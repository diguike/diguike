### KeepMyMacAwake：离开时让 Mac 接着干活

<a href="https://github.com/diguike/KeepMyMacAwake"><img src="https://raw.githubusercontent.com/diguike/KeepMyMacAwake/main/docs/images/overview-light.png" alt="KeepMyMacAwake 控制窗口与菜单栏面板" width="640" /></a>

让 Claude Code / Codex 跑一轮长重构，人去吃饭、开会、睡觉，回来发现 Mac 早睡着了，任务停在半路。我自己被坑了好几次，就写了这个菜单栏小工具，现在每天都开着。

- 选个场景（日常 / 夜间 / 合盖），定个时长，到点自动恢复正常睡眠，不用再敲 `caffeinate`
- 合盖也能跑；默认只在接电时生效，过热、电量低会自己停
- 原生 Swift，macOS 14+，免费开源

[下载 Mac 版](https://github.com/diguike/KeepMyMacAwake/releases) · [源码](https://github.com/diguike/KeepMyMacAwake)
